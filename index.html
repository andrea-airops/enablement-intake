Done-with-you
Structured Ramp
What's included
  • 4–6 weekly use case clinics (60 min live)
  • Rotating guest builders (AirOps team or customers)
  • Train-the-trainer arc — one internal person becomes the go-to
  • Full-day onsite (or virtual) build day
  • Post-engagement workflow audit + handoff doc
Ideal customer profile
  • Has 1+ use cases already scoped
  • Wants to build capability, not just deliverables
  • Has a technical champion who can multiply
  • Can commit to weekly 1-hr sessions for 4–6 weeks
Prerequisites
  • 3–5 use cases documented before kickoff
  • Identified train-the-trainer candidate
SA-adjacent
Debug & Optimize
What's included
  • Deep-dive workflow audit (1–3 workflows)
  • Side-by-side debugging session with Andrea
  • Good/bad output analysis + prompt rewrite
  • Config recommendations + documentation
  • 30-day async follow-up window
Inputs required
  • Workflow access (shared link or read-only)
  • 5+ good output examples
  • 5+ bad output examples with notes
  • Current config screenshots or export
Best for
  • Workflows already running in production
  • Customization + troubleshooting needs
  • Output quality issues or edge case failures
Compressed intensive
AI Fluency Sprint
What's included
  • 2-day immersive (can be split across 2 weeks)
  • Day 1 — AI thinking fundamentals: prompt design, output evaluation, workflow logic
  • Day 2 — Hands-on AirOps builds: live use case construction from scratch
  • Shared resource doc + prompt pattern library
  • Optional 30-min async debrief in the following week
Ideal customer profile
  • Team needs fast AI upskill before a launch, pitch, or org rollout
  • Can't commit to a multi-week program
  • Mix of beginners and passionate builders — accelerates team-wide AI adoption from multiple starting points
  • Leadership wants tangible output from a short engagement
Prerequisites
  • AirOps accounts provisioned before Day 1
  • 1–2 real use cases submitted in advance for Day 2 context
  • Full team availability for both days
No fixed curriculum
Open Q&A / Clinic
What's included
  • 1–3 open sessions (60–90 min each)
  • Customer brings questions, agenda, or blockers
  • Andrea facilitates and steers discussion
  • Light session recap doc sent afterwards
  • No formal homework or deliverables
Ideal customer profile
  • Already building — wants expert time
  • Small team (1–5 people) with targeted questions
  • No bandwidth for a multi-week engagement
  • Scheduling can be ad hoc
Prerequisites
  • Basic AirOps familiarity (not for beginners)
  • Arrive with 3–5 specific questions or blockers
